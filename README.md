# Personalized Healthcare Recommendation System

## Project Overview
An AI and Machine Learning based educational
prototype that provides personalized health
information recommendations.

## Technologies Used
- Python
- Machine Learning
- Random Forest
- TF-IDF
- Cosine Similarity
- Streamlit
- Pandas and NumPy
- Scikit-learn

## Main Features
1. Healthcare Dashboard
2. Health Prediction (experimental classification)
3. Personalized Health Information Recommendations
4. Data Analytics
5. Project Information

## How to Run

Install dependencies:

pip install -r requirements.txt

Run the application:

python -m streamlit run app.py/streamlit_app.py

## Disclaimer
This project is an educational prototype.
It is not intended for medical diagnosis,
treatment decisions, or medication advice.
